# 求职 ATS 模式（job-ats）

求职全流程工作台：找岗位 → 分析匹配 → 优化简历 → 管理投递 → 模拟面试。

## 使用方式

1. 在 Web GUI 新建会话时，预设选择器里选「求职 ATS 模式」；
2. 会话顶部会出现七个标签页：**职位搜索 / 筛选工作 / 工作分析 / ATS 优化 / 简历库 / 投递追踪 / 模拟面试**；
3. 所有状态保存在会话工作区的 `.ats/` 目录。

## 典型流程

- **找岗位**：「职位搜索」里设关键词+城市，一键聚合 Boss直聘 / 实习僧 / OfferShow / 全网，可开定时刷新自动搜索；看中的岗位点「🚀 一键代投」（打招呼语自动复制 + 打开岗位页粘贴发送，同步写入投递追踪）；对话里也可以让助手搜索（如「帮我找 10 个北京后端实习岗」）→ 岗位自动出现在「筛选工作」；
- **分析**：标签页点「去分析」→ 对话里让助手分析 → 「工作分析」看匹配度、匹配点与缺口、关键词命中；
- **ATS 优化**：先在「简历库」解析简历（点「解析入库」→ 对话里让助手解析）→ 「ATS 优化」新建任务选简历与目标岗位 → 对话里让助手起草 → 回到标签页点击区块/句子/拖选文字，用覆盖菜单（重写/无关/直接消除/精简/适配/数据化/自定义）定点修改 → 缺失板块决定补或不补 → 选风格主题，一键导出 Word/PDF；导出前可点「🔍 ATS 解析校验」模拟 ATS 对 Word 做纯文本提取并报告关键词命中/缺失；可生成求职信并「含求职信导出」（附在简历后另起一页）；
- **投递追踪**：表格/看板双模式（开关在面板内「视图」处，选择会被记住），记录职位、公司、链接、类型、当前步骤、DDL、下一步行动；看板直接拖动卡片更新进度；
- **模拟面试**：HR面 → 技术面 → 群面（多个 AI 组员）→ 主管面 → 终面；「开始模拟面试」自动把开场指令填入输入框；常见问题支持 🔊 朗读（模拟 HR 电话）。

## 组成

- `agent.cordis.yml` + `preset.yml`：本 preset（persona + 标准工具 + `dsh-job-ats` 模型工具 `ats_*`）；
- `skills/ats-job/SKILL.md`：助手的工作手册（数据文件约定、各标签页工作流、铁律）；
- 浏览器标签页与 HTTP API 由 `dsh-job-ats` 包提供（位于 `~/.dsh/profiles/web/packages/dsh-job-ats/`，宿主平面行见 `~/.dsh/profiles/web/cordis.patch.yml`）。
